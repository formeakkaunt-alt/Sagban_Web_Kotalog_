# Веб-сайт-каталог торговой марки «SAGBAN»

Премиальный, минималистичный и современный веб-сайт-каталог мясной продукции торговой марки **«SAGBAN»**.

---

## 🎨 Особенности проекта

- **Цветовая палитра**: Светлый молочно-кремовый фон (`#FAF8F5`), глубокий тёмно-бордовый акцент (`#520D1A`), чистый белый цвет для рамок и контрастный тёмный текст.
- **Минимализм и чистота**: Полное отсутствие визуального шума, рекламных блоков и лишних элементов.
- **Плавные анимации**: Все взаимодействия (hover, переходы, открытие Lightbox) выполнены с премиальной плавностью (300–500 мс).
- **Горизонтальное расположение**: 4 категории продукции («Варёная колбаса», «Сосиски и сардельки», «Копчёная колбаса», «Мясные деликатесы») на десктопе выстроены в один горизонтальный ряд, на смартфонах — адаптируются под экран.
- **Маршруты категорий**: Каждая категория открывается на отдельной странице (`/catalog/varenaya-kolbasa`, `/catalog/sosiski-sardelki`, `/catalog/kopchenaya-kolbasa`, `/catalog/myasnye-delikatesy`).
- **Lightbox просмотр**: Увеличение фотографий с затемнением фона и навигацией «Вперед/Назад» стрелками или клавишами клавиатуры.

---

## 🚀 Запуск проекта

### Локальная разработка:
```bash
npm run dev
```
Откройте браузер по адресу: `http://localhost:5173`

### Сборка для публикации (Production build):
```bash
npm run build
```
Готовые оптимизированные статические файлы будут в папке `dist/`.

## 📸 Как добавлять и заменять фотографии продукции

Все данные каталога вынесены в отдельный файл [`src/data/catalogData.js`](src/data/catalogData.js).

### Шаг 1: Сохраните фотографию
Поместите файл изображения в папку `public/images/products/` (например, `public/images/products/varenaya-1.jpg`).

### Шаг 2: Укажите путь в `src/data/catalogData.js`
Найдите нужный каталог (`sagban` или `premiyum`) и нужную категорию:

```javascript
'varenaya-kolbasa': [
  { 
    id: 'sag-var-1', 
    image: '/images/products/varenaya-1.jpg', // путь к вашей фотографии
    isPlaceholder: false 
  },
  // добавляйте следующие фото по мере готовности:
  { 
    id: 'sag-var-2', 
    image: '/images/products/varenaya-2.jpg', 
    isPlaceholder: false 
  },
]
```

Карточка автоматически обновится и отобразит вашу фотографию в высоком качестве с поддержкой полноэкранного Lightbox.
